# GVCR Citation Maker

Made by x3alpy (Tool Creator), ababyboi (Revamp), 27vq (Windows App Porter) and civoc (macOS App Porter)  

Citation Maker Tool for GVCR Law Enforcement to generate citations, arrest reports, and warrant requests quickly and efficiently. 

The app is completely secure and does not store any data on servers.

The code is open source if you want to verify its security and privacy.

Implemented by executives.

Usage for things outside of GVCR purposes must first be contacted to me (ababyboi, Discord) before waiting for approval.
